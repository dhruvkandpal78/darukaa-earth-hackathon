# Using Darukaa Earth

1. **Explore the sample.** The first screen contains fictional restoration projects and clearly marked synthetic data. Filters update the map, summary cards, and charts together. Search project names, regions, or site names.
2. **Navigate at any zoom.** The left sidebar is visible when the window is wide enough. The persistent Menu button opens the complete navigation in narrow or zoomed-in windows. Escape closes the menu. No zoom adjustment is necessary.
3. **Create an account.** Choose Create your workspace, then Create account. Use a name, email, and a password of at least twelve characters. The Python service and database must be running. Your private portfolio begins empty.
4. **Create a project.** Choose New project, enter a name and region, choose a focus, and optionally explain the goal. A successful save adds the project to the portfolio.
5. **Add a site.** Use Add site on a project card or the map panel. Move/zoom to the intended location. Click at least three corners and choose Finish boundary. Use Undo to adjust the most recent corner or pause drawing to pan without adding points. Supply the site name and ecosystem, then save.
6. **Inspect performance.** Click a numbered map marker, a boundary, or a site in a list. The detail window shows area, carbon, biodiversity, canopy cover, and a selectable interactive chart. Newly created sites correctly show no observations.
7. **Compare time periods.** Use the portfolio chart's period selector for the last 3, 6, or 12 available observation months. Hover or tap chart points for exact values.
8. **Export observations.** Use Export CSV in a site detail window or Export data in Analytics. Empty datasets cannot be exported. The CSV contains underlying values and their dates, not a screenshot of the chart.
9. **Load your data.** Ask the system operator to import an observations CSV with the documented command. Re-enter the account to load the updated series.
10. **Sign out.** Choose your account at the bottom of the sidebar. This clears the token and private portfolio from the interface and returns to the sample.

Animations respect the device's reduced-motion setting. Dialogs keep keyboard focus inside the active form. The site list provides the same selection workflow as the map if WebGL is unavailable.
